## About

SVOP is an open-source harness for Claude Code: an orchestrator chat plus teams of AI agents that plan, design, build, review and ship, while the owner only decides. It is a few plain rule, agent and skill files installed into a project's `.claude/` folder, for a single owner who wants to build products without learning to code.

## Principles

- **Simple and useful, or not at all.** Everyone already has a mental model of how work gets done. A new concept, file or rule earns its place only if it is clear, simple and helps right away. Otherwise leave it out.
